## 📋 项目概述

本项目旨在开发一个FlowUs个人主页管理平台，帮助用户高效管理FlowUs上的内容并进行数据分析。核心功能包括完整的内容管理、多维度数据分析、多格式导出能力，以及混合数据更新模式。

**目标用户**: 拥有FlowUs个人主页的用户，希望集中管理内容并深入了解内容表现情况

**核心价值**:
- 集中管理FlowUs主页内容，提升内容创作和整理效率
- 提供全面的数据分析视图，帮助用户了解内容表现
- 支持多格式导出，便于数据备份和二次利用
- 灵活的更新机制，满足不同使用场景需求

## 🏗️ 架构设计

### 技术选型
- **前端框架**: React 18 + TypeScript
- **后端框架**: Node.js + Express
- **状态管理**: React Context + useReducer
- **样式方案**: Tailwind CSS
- **数据存储**: 浏览器LocalStorage + IndexedDB
- **图表库**: Recharts / ECharts
- **构建工具**: Vite

### 项目结构
```
flowus-manager/
├── src/
│   ├── components/          # UI组件
│   │   ├── common/          # 通用组件
│   │   ├── content/         # 内容管理组件
│   │   ├── analytics/      # 数据分析组件

│   ├── pages/               # 页面组件

│   │   ├── Analytics/       # 数据分析页面
│   │   └── Settings/        # 设置页面
│   ├── services/            # API服务层
│   │   ├── flowus.ts        # FlowUs API调用
│   │   ├── analytics.ts     # 数据分析服务
│   │   └── storage.ts       # 本地存储服务
│   ├── hooks/               # 自定义Hooks
│   ├── types/               # TypeScript类型定义
│   ├── utils/               # 工具函数

│   ├── controllers/         # 控制器
│   └── middleware/           # 中间件
```

### 前后端集成模式
采用单体Web应用架构，前端构建为静态资源，由Express服务器提供服务。FlowUs API调用通过后端代理进行，避免跨域限制并保护API密钥安全。

## 🎯 功能模块设计

### 1. 内容管理模块

#### 1.1 文章管理
- **文章列表**: 分页展示所有文章，支持搜索、筛选、排序
- **文章详情**: 查看文章完整内容、阅读量、更新时间
- **快速编辑**: 一键跳转到FlowUs编辑器
- **批量操作**: 批量选择、批量导出、批量删除

#### 1.2 页面管理
- **页面树形结构**: 展示页面层级关系
- **页面属性**: 查看页面类型、访问权限、创建时间
- **页面跳转**: 快速打开页面进行编辑

#### 1.3 分类与标签
- **分类管理**: 创建、编辑、删除文章分类
- **标签系统**: 为文章添加和管理标签
- **批量打标**: 批量为文章添加标签

#### 1.4 多媒体管理
- **文件列表**: 查看已上传的多媒体文件
- **文件预览**: 图片预览、视频播放
- **文件统计**: 各类型文件占用空间统计

### 2. 数据分析模块

#### 2.1 访问数据分析
- **总访问量**: 累计访问次数和独立访客数
- **趋势图**: 日/周/月访问量变化趋势
- **访问来源**: 直接访问、外部链接、搜索引擎占比
- **热门页面**: 访问量最高的Top 10页面

#### 2.2 互动数据分析
- **点赞统计**: 总点赞数、篇均点赞、增长趋势
- **评论分析**: 评论数量、评论用户分布
- **分享数据**: 各平台分享次数统计
- **收藏统计**: 文章收藏数量和收藏率

#### 2.3 内容表现分析
- **内容排行**: 按访问量、互动量排列文章
- **阅读完成率**: 平均阅读进度和完读率
- **停留时间**: 平均页面停留时长
- **内容更新频率**: 文章更新周期分析

#### 2.4 可视化报表
- **仪表盘**: 关键指标一目了然
- **趋势图**: 访问量和互动量变化趋势
- **饼图/柱状图**: 数据分布可视化
- **数据对比**: 同比/环比数据对比

### 3. 导出功能模块

#### 3.1 内容导出
- **PDF导出**: 生成精美PDF文档
- **Markdown导出**: 保持格式的Markdown文件
- **Word导出**: 可编辑的DOCX文档
- **Excel导出**: 结构化数据表格
- **JSON导出**: 完整数据结构
- **CSV导出**: 便于数据分析

#### 3.2 数据导出
- **分析报告**: 完整的数据分析报告（PDF）
- **原始数据**: CSV/JSON格式的原始数据
- **自定义导出**: 选择特定指标和日期范围

#### 3.3 批量导出
- **批量文章**: 一次性导出多篇文章
- **定时导出**: 设置自动导出任务
- **导出模板**: 自定义导出格式模板

### 4. 系统设置模块

#### 4.1 FlowUs连接
- **API配置**: 输入FlowUs API密钥
- **连接测试**: 验证API连接是否正常
- **数据同步**: 手动触发数据同步

#### 4.2 同步设置
- **定时同步**: 配置自动同步频率（每小时/每天/每周）
- **同步范围**: 选择同步哪些类型的数据
- **冲突处理**: 数据冲突时的处理策略

#### 4.3 界面设置
- **主题切换**: 浅色/深色模式
- **语言设置**: 界面语言选择
- **通知设置**: 提醒和通知配置

## 📊 数据流设计

### FlowUs API数据流
```
用户操作 → React组件 → API Service → Express后端 → FlowUs API
                ↓
         本地状态更新
                ↓
         LocalStorage缓存
```

### 数据更新机制
1. **手动刷新**: 用户点击刷新按钮，立即同步最新数据
2. **定时同步**: 依据设置的时间间隔，自动执行同步任务
3. **增量更新**: 仅同步新增或修改的数据，优化性能

### 数据存储策略
- **实时数据**: 保存在React组件状态中
- **缓存数据**: LocalStorage存储最近同步的数据
- **离线支持**: IndexedDB存储完整数据，支持离线查看

## 🔐 安全考虑

### API密钥保护
- API密钥仅存储在后端，不暴露给前端
- 使用环境变量管理敏感配置
- 支持密钥更新和撤销

### 数据安全
- 本地数据加密存储
- 定时清理过期缓存数据
- 提供数据导出备份功能
