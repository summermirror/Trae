# FlowUs论文同步功能使用指南

## 🎯 功能概述

FlowUs Manager 现在支持直接从 FlowUs 页面同步论文列表到本地论文管理功能。

## 📝 使用步骤

### 第一步：配置 API 令牌

1. 打开应用，进入"设置"页面
2. 在"API配置"区域输入你的 FlowUs API 令牌
3. 点击"测试连接"确保令牌有效
4. 保存设置

### 第二步：同步论文

#### 方法一：从论文管理页面同步（推荐）

1. 点击左侧导航的"论文管理"
2. 点击绿色的"同步FlowUs论文"按钮
3. 等待同步完成
4. 系统会自动导入论文到本地

#### 方法二：从导出中心同步

1. 点击左侧导航的"导出中心"
2. 点击"论文管理"标签
3. 点击"同步FlowUs论文"按钮
4. 等待同步完成

## 🔧 技术说明

### 同步的论文信息

同步功能会自动提取以下信息：
- **标题** - 论文名称
- **作者** - 所有作者列表
- **期刊** - 发表期刊/会议
- **年份** - 发表年份
- **DOI** - 数字对象标识符
- **URL** - 在线链接
- **摘要** - 论文摘要
- **关键词** - 相关关键词

### 数据存储

所有论文数据保存在本地浏览器的 LocalStorage 中：
- ✅ 无需登录账号
- ✅ 数据完全私有
- ✅ 换设备需要重新同步

## 💡 常见问题

### Q: 同步失败怎么办？

**A:** 请检查以下几点：
1. ✅ 是否已在设置页面配置 API 令牌
2. ✅ API 令牌是否有效（点击"测试连接"）
3. ✅ 网络连接是否正常
4. ✅ FlowUs 页面是否存在且包含论文数据

### Q: 同步的论文数量为 0？

**A:** 可能的原因：
1. FlowUs 页面中没有符合格式的论文数据
2. API 权限不足，无法访问该页面
3. 页面结构不包含论文属性（如标题、作者等）

**解决方案：**
- 手动添加论文
- 从其他格式导入（JSON、CSV、BibTeX）
- 检查 FlowUs 页面结构

### Q: 数据会丢失吗？

**A:** LocalStorage 的数据：
- 清理浏览器数据时会丢失
- 更换浏览器或设备时会丢失
- 建议定期导出备份

### Q: 如何备份论文数据？

**A:** 导出功能支持多种格式：
1. 进入"论文管理"页面
2. 点击"导出"按钮
3. 选择格式（推荐 JSON）
4. 下载备份文件

## 🎨 完整功能

### 论文管理功能

除了同步，你还可以：

1. **添加论文** - 手动输入论文信息
2. **编辑论文** - 修改论文详情
3. **删除论文** - 移除不需要的论文
4. **搜索论文** - 按标题、作者、关键词搜索
5. **查看详情** - 查看完整的论文信息
6. **打开链接** - 直接访问论文在线页面

### 导出功能

支持多种导出格式：
- **JSON** - 完整数据备份
- **CSV** - Excel 表格格式
- **BibTeX** - LaTeX 引用格式
- **RIS** - 学术文献标准
- **Markdown** - 文档格式
- **Word** - Word 文档格式

### 导入功能

支持多种导入格式：
- **JSON** - 从 JSON 文件导入
- **CSV** - 从 Excel/CSV 文件导入
- **BibTeX** - 从 BibTeX 文件导入
- **纯文本** - 从文本内容导入

## 🔄 定期维护

### 建议的工作流程

1. **首次设置**
   - 配置 API 令牌
   - 同步论文到本地
   - 导出备份

2. **日常使用**
   - 在论文管理页面查看和整理
   - 添加个人笔记和标签
   - 搜索和筛选论文

3. **定期备份**
   - 每周或每月导出一次
   - 保存到云存储
   - 需要时重新导入

## 📞 故障排除

### 错误信息及解决方案

| 错误信息 | 可能原因 | 解决方案 |
|---------|---------|---------|
| "请先配置API令牌" | 未设置令牌 | 去设置页面配置令牌 |
| "同步失败" | 网络或API问题 | 检查网络和令牌 |
| "未找到论文数据" | 页面格式不匹配 | 使用手动添加或导入 |

### 调试技巧

1. **打开浏览器控制台**
   - 按 F12 或 Ctrl+Shift+I
   - 查看错误信息

2. **检查 API 令牌**
   - 确保令牌未过期
   - 确保有足够权限

3. **验证页面内容**
   - 直接访问 FlowUs 页面
   - 确认页面包含论文数据
